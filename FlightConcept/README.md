# Flight Concept

This workspace is a personal concept project for exploring a single-seat flying vehicle through sketches, visual references, and early 3D layouts. It is not an engineering design or a flight-ready aircraft project.

## Start here

Open `CAD/FlightConcept_Master.FCStd` in FreeCAD. The document contains the master parameter sheet and reference sketches, plus imported seated-mannequin and racing-seat mesh assets for the first occupant-layout study. The current study is limited to the occupant and seat; no dashboard, steering wheel, or pedals are included.

All model dimensions use millimetres. The mesh assets are visual references and do not provide editable production geometry. Their source files and licence notes are in `References/README.md`.

## Project structure

- `CAD/`: master FreeCAD document and later component documents.
- `CAD/Components/`: future modular component files.
- `Drawings/`: concept sheets and later drawing outputs.
- `Exports/`: view previews and neutral-format exports.
- `Ideas/`: prompt notes and design decisions.
- `References/`: original assets and their source and licence notes.

The master document is the starting point. Separate component files can be added later if the concept grows into distinct assemblies.

# Reference Assets

These CC0 mesh assets are used only to explore the appearance and relative placement of a seated occupant and seat in the early concept model. Both source GLB files are retained alongside FreeCAD-compatible STL conversions. The conversions were rotated into the project axes (+X forward, +Z up) and scaled from metres to millimetres.

## Seated mannequin

- Asset: [Seated display mannequin](https://3dassets.dev/assets/retail-store-fixtures-and-mall-mannequin-seated-05ab1b9a)
- Source file: `Seated_Mannequin_CC0.glb`
- FreeCAD mesh: `Seated_Mannequin_CC0.stl`
- Reported height: 1400 mm
- Licence: CC0 1.0 Universal

This is a stylized display mannequin, not an anthropometric or safety dummy. It is a visual placeholder for posture and packaging studies.

## Racing seat

- Asset: [Race seat insert on stand](https://3dassets.dev/assets/endurance-and-gt-paddock-seat-insert-e0a8d29b)
- Source file: `Race_Seat_CC0.glb`
- FreeCAD mesh: `Race_Seat_CC0.stl`
- Reported bounds: 640 × 1060 × 655 mm
- Licence: CC0 1.0 Universal

The source asset is a low-poly seat insert shown on a stand. Its shape is a starting reference and should be replaced or adjusted when the user selects a closer seat design.

## Use limits

The meshes are faceted visual references. They are not dimensionally certified, ergonomic validation models, material definitions, or manufacturing geometry. Dimensions shown in concept drawings must be treated as approximate unless separately defined in the master parameter sheet.
